# Security policy — Vtechiee GST Billing Software

This is an independent source edition, not a validated production release. No supported release is designated yet.

Report vulnerabilities privately through this repository's Security tab if private vulnerability reporting is enabled. Do not post vulnerability details, real GSTINs, invoices, credentials or customer records in public issues. If private reporting is unavailable, request a private reporting channel from the repository maintainer without disclosing the issue publicly.

The app is intended for local, single-user use. Keep its server bound to loopback; do not expose it to the Internet or an untrusted LAN. Review dependencies, local API access controls, backup/restore and update integrity before production use.

Upstream security policy and historical audit notes are not certification of this edition.
